# Microgrid-Assessment-for-Nyabiheke-and-Kigeme-Refuge-Camp
Microgrid assessment case study Evaluates Nyabiheke Hall system performance using PV yields, performance ratio, inverter headroom, and battery reserve analysis. Includes Jupyter notebooks for data quality, PV calibration (k=0.795), efficiency metrics, and service feasibility. Python, pandas, matplotlib.
